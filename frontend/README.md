# GovLaunch Frontend

React 18 + Vite frontend for the GovLaunch Government–Startup Innovation Procurement Platform.

**Smart India Hackathon 2026 | PS ID: SIH2026-26136 | NSUT**

## Stack
- React 18, Vite 8
- motion/react (animations)
- lucide-react (icons)
- react-i18next (8 languages: EN, HI, MR, BN, TA, TE, KN, ML)
- Inline styles (no Tailwind)

## Run
```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

## Environment
Copy `.env.example` to `.env`:
```
VITE_API_BASE_URL=http://localhost:8000
VITE_GOOGLE_CLIENT_ID=...
```

See `docs/README.md` for full project documentation.
